# Lab 3.1: Features and Overfitting in the Browser

Chapter 3, The Machine Learning You Need · No code · About 45 minutes · Last checked: 2026-11-24, checkpoints run in a browser (TensorFlow Playground at https://playground.tensorflow.org, controls as listed below)

## Goal

See with your own eyes two ideas from Chapter 3: a well-chosen feature can make a model both simpler and easier to explain, and a model that fits its training data well can still fail on data it has not seen.

## Tools and versions

A web browser and TensorFlow Playground (https://playground.tensorflow.org), a free interactive neural network demo that runs entirely in the browser and needs no account. On 2026-11-24 it offered four classification datasets (circle, exclusive or, Gaussian, spiral), seven input features (X1, X2, X1 squared, X2 squared, X1 times X2, sin X1, sin X2), and controls named "Ratio of training to test data", "Noise", "Batch size", "Learning rate", "Activation", "Regularization rate", "Show test data" and "Discretize output". If the site has changed, the tools page of this repository names an alternative; the steps below still describe what to try.

A second option for the same ideas: any spreadsheet with a scatter chart. Steps 1 and 2 can be done by plotting points on a circle and adding a column for x squared plus y squared.

## Data

Synthetic two-dimensional points generated by the Playground itself. No personal data.

## Steps

### Part A: a feature that does the work (about 15 minutes)

1. Choose the **circle** dataset. Keep only the features **X1** and **X2** selected. Reduce the network to **one hidden layer with a single neuron** (use the minus buttons for layers and for neurons). One neuron computes one weighted sum of the inputs, so the boundary it can draw on X1 and X2 is a straight line. (Do not remove the last hidden layer: on 2026-11-24, with zero hidden layers and the squared features of step 3, the Playground's output unit saturated and training stalled near a test loss of 0.9 to 1.0 in three of three runs.)
2. Press play and let it run for about 300 epochs.
   **Checkpoint A1:** test loss stays high (around 0.4 or above) and the decision boundary is a straight line that cannot separate the inner circle from the outer ring.
3. Reset. Deselect X1 and X2; select **X1 squared** and **X2 squared** instead. Keep the single hidden neuron. Run again.
   **Checkpoint A2:** test loss falls close to zero within about 50 epochs, and the boundary is a closed curve around the center.
4. Hover over the two lines from the features to the hidden neuron. Note the sign and rough size of each weight.
   **Checkpoint A3:** both weights have the same sign and similar size. Together they say one thing: "the farther a point is from the center, the more it belongs to the outer class." Write that sentence down; it is a complete explanation of the model.
5. Now go back to X1 and X2 only, add two hidden layers of four neurons each, and run. The network solves the problem too.
   **Checkpoint A4:** the network reaches a low test loss, but it now has dozens of weights. Try to write a one-sentence explanation of it from the weights. You will not manage it as easily as in step 4.

### Part B: training loss versus test loss (about 20 minutes)

6. Choose the **spiral** dataset. Set "Ratio of training to test data" to **10%**, "Noise" to **50**, and tick **Show test data**. Select all seven features and build a large network (for example three hidden layers of eight neurons).
7. Run for about 1,000 epochs while you watch the two numbers at the top right: training loss and test loss.
   **Checkpoint B1:** training loss keeps falling while test loss stalls or rises. The boundary snakes around individual training points. This is overfitting.
8. Raise "Ratio of training to test data" to **70%** and run again from a reset.
   **Checkpoint B2:** the gap between training and test loss narrows. More data is the oldest cure for overfitting.
9. Optional: with 10% training data again, set "Regularization" to L2 and "Regularization rate" to 0.01 or 0.03. Watch what happens to the boundary and to the gap.

### Part C: write it up (about 10 minutes)

10. Answer the questions below in your own words.

## Expected results

Part A: the single neuron on X1 and X2 fails (test loss about 0.4 or higher); the same single neuron on the two squared features succeeds (test loss near 0). In the 2026-11-24 check, these were 0.41 and 0.001 after 300 and 150 epochs; in Part B, training and test loss after 1,000 epochs were 0.000 and 0.63 at 10% training data, and 0.03 and 0.07 at 70%. Part B: with 10% training data and noise 50 the training loss ends well below the test loss; with 70% the two are closer. Exact numbers vary from run to run because the Playground uses random initial weights and random data.
