# Chapter 26 labs: Casebook: Explainability Across Industries

| Lab | Title | Kind | Time |
|---|---|---|---|
| [lab1](lab1/) | Reading a case with the loop: two cases from their primary sources | No code (browser and template) | about 60 minutes |
| [lab2](lab2/) | A readable middle: a two-stage pipeline, a device shift and a repair (healthcare case) | Run-only notebook | about 45 minutes |
| [lab3](lab3/) | A screening score is a rank: ventile scores, a household maximum and default screen-in (public sector case) | Run-only notebook | about 45 minutes |

All notebooks were run end to end on 2026-11-24 with Python 3.10 on a laptop CPU; each runs in a few seconds.

- Labs 26.2 and 26.3 use the main environment in `env/requirements.txt` and need only numpy 2.2.6, pandas 2.3.3, scikit-learn 1.7.2 and matplotlib 3.10.9 (Jupyter kernel used for the check run: `xai-lab-venv`).
- All data in Labs 26.2 and 26.3 are synthetic and generated inside the notebooks. They illustrate design ideas from the chapter's cases; they do not reproduce any real system, population or result.
- `lab1/casebook-template.md` is the template used throughout the chapter and in the Chapter 26 portfolio assignment (the sector brief).
