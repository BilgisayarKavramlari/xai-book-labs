# Chapter 22 labs: Explanations for People

| Lab | Title | Kind | Time |
|---|---|---|---|
| [lab1](lab1/) | Write for the affected person, then test it | No code (worksheet and three volunteers) | about 90 minutes |
| [lab2](lab2/) | Did the explanation help? Analyzing a reliance study | Notebook, with a run-only path | about 60 minutes |
| [lab3](lab3/) | Numbers people can read | Run-only notebook | about 60 minutes |
| [lab4](lab4/) | Inform or persuade? An offer explanation audit | No code (cards and fact sheet) | about 45 minutes |

Both notebooks were run end to end on 2026-11-24 on a laptop CPU with Python 3.10 (under 5 seconds each), using the main environment (`env/requirements.txt`): numpy 2.2.6, pandas 2.3.3, scikit-learn 1.7.2, matplotlib 3.10.9; Jupyter kernel `xai-lab-venv`.
All data are synthetic and generated with fixed seeds. Passengers, patients, airlines, hospitals and offers in the labs are invented for teaching. No lab needs an account or an API key.
Labs 22.1 and 22.4 involve other people only as volunteers reading invented cases: ask for consent, collect no names and tell them the cases are invented.
